# ADR：智能体回复改用 Markdown 渲染

日期：2026-09-02

**背景**：智能体输出为 Markdown（标题/列表/内嵌图片 `![alt](url)`），原实现按「纯文本+正则扫图」渲染，导致图文错位、图片重复显示，两次正则补丁（扫 URL + 删源码）治标不治本。

**决策**：引入 react-markdown + remark-gfm，回复整体走 Markdown 渲染；删除 extractImages 与图片过滤正则；仅保留 think 标签输入净化。

**理由**：图片在原文位置就地渲染，顺序天然正确；删码多于加码；支持标题/列表/表格/代码。

**风险**：流式期间未闭合的 Markdown 语法（如图片 URL 传一半）会短暂显示异常，闭合后自动恢复，可接受。
