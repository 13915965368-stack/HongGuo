# 交接提示词：弘果小站前端视觉重构（给有视觉能力的 AI）

> 用法：把本文件全文 + `frontend-design-spec.md` 全文一起发给接手的 AI。画布链接供其对照视觉。

---

## 背景

这是一个个人网站项目「弘果小站」，第一个功能模块是接入扣子（Coze）智能体的 AI 助手聊天页。**功能已全部联调通过，现在只做视觉重构**，把现有的默认蓝色样式替换为已定稿的「构成主义」设计。

## 技术现状（不要破坏的部分）

- 项目路径：`E:\HongGuo`（前端 `web/`：React 18 + Vite 5，纯 CSS 无框架；后端 `server/`：Express 代理，**不要动**）
- 前端只有 3 个源码文件：`web/src/App.jsx`、`web/src/App.css`、`web/src/main.jsx`
- `App.jsx` 现有逻辑必须原样保留：
  - `streamChat()`：SSE 流式解析，不要改
  - `sanitizeText()`：清除模型泄漏标签，不要改
  - `getSessionId()` / localStorage 多轮对话方案，不要改
  - react-markdown + remark-gfm 渲染（智能体输出是 Markdown，图片以 `![alt](url)` 内嵌），不要改
  - Enter 发送 / Shift+Enter 换行，不要改
- 当前界面：单页聊天（顶栏 + 消息列表 + 输入条），单会话，无路由
- 启动方式：`cd web && npm run dev`（后端 `cd server && node src/index.js`，/api/chat 已代理）

## 设计资源

1. **设计规范**（主依据）：`E:\HongGuo\设计规范\frontend-design-spec.md` —— token、字阶、边框/阴影梯度、组件规格、布局、禁忌，全部以它为准
2. **设计稿**（对照感觉）：https://ardot.tencent.com/file/721510631726258 →「正式稿 · 构成主义」页面，含主页和对话页两帧
3. 风格起源规格存档：`.workbuddy/stylekit-specs/constructivism.html`（可查可不看）

风格一句话：泛黄纸底 + 苏维埃红 + 墨黑，全部直角、粗黑边框（2/3/4px）、硬边偏移阴影（无模糊）、黑体粗标题、对角斜带装饰。**禁止圆角、渐变、灰色、第六种颜色。**

## 任务（分两阶段，按顺序做）

### 阶段 1：现有聊天页换肤（纯样式，不改逻辑）
- 用规范 §1 的 CSS 变量重写 `App.css`（`:root` 定义 token）
- 按规范 §2.5/§2.6 重绘：AI 气泡（纸色+3px黑框+硬阴影+红色方块头像）、用户气泡（黑底+红阴影+右对齐）、流式光标（3×16 红色竖条替换现在的三点动画）、输入条（黑框+红色方块发送键）
- Markdown 渲染元素（代码块/引用/表格/链接）按规范 token 重新配色，图片边框改为 `3px solid var(--ink)` 且 `border-radius: 0`
- 错误提示用 `--red`，`.empty` 空态文字用 `--ink` + 透明度
- 顶栏按规范 §2.1：红方块 Logo + 3px 粗黑底线

### 阶段 2：主页 + 侧栏（需要动结构，先和我确认再动手）
- 新增主页（对应设计稿主页帧）：导航、Hero（72px 标题 + 底部红黑斜带 `rotate(-8deg)`）、模块 01 卡片、未来模块占位卡、黑色页脚
- 聊天页加左侧会话历史栏（264px `--paper-deep` 底 + 3px 粗竖线分隔，当前会话红底黑框）
- 需要引入 react-router 和多会话存储方案——**动手前先把方案讲清楚，等我确认**

## 硬性约束

1. 不改 `server/` 任何文件；不改 `App.jsx` 中 §技术现状列出的逻辑
2. 严格只用规范的 6 个色值；`border-radius` 恒为 0；阴影 blur 恒为 0
3. 图标一律内联 SVG，禁止 emoji
4. 字体：Noto Sans SC（中文）+ Inter（英文标签），用 Google Fonts CDN 引入
5. 文案中的站名统一用「**弘果**」（现有代码里是"红果"，以设计稿为准）
6. 每完成一个阶段先跑起来自测：发消息 → 流式回复 → 图片消息 → 多轮上下文，确认无回归再进入下一阶段

## 验收标准

- 阶段 1 完成后：聊天页视觉与设计稿对话页一致，且完整走通「发消息→流式输出→图文混排→多轮对话」无报错
- 对照检查方式：你自己截图与设计稿逐区块比对，重点看边框粗细、阴影方向、是否有漏网的圆角和灰色
