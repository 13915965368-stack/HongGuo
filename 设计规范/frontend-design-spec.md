## 0. v2 风格强化补丁（2026-09-02，优先级高于下文冲突项）

用户反馈初版"配色对但风格平淡"，按 StyleKit Constructivism 硬提示词强化：

1. **字重**：标题一律 **900（Black）**，CDN 字重扩展为 Noto Sans SC 400/700/900 + Inter 700/900；极端字重对比（巨型标题 vs 小正文）
2. **导航**：改为**墨黑底** + 纸色字；导航标签块化（2px 纸框小方块，当前项红底）
3. **按钮交互三定律**（所有主/次/发送按钮）：
   - *Block Invasion*：`::before` 覆盖层初始 `translateX(-101%)`，hover 时 `100ms linear` 横扫进入
   - *Diagonal Aggression*：hover 时 X+Y 同时位移 4px + 阴影同步缩小/归零
   - *Soviet Reversal*：active 时红黑配色翻转（墨底→红底墨字，红底→墨底红字），阴影骤归零
4. **机械缓动**：一切动效 `75~100ms ease-linear`，禁止 ease-out/ease-in-out
5. **Hero v2**：巨型标题（160px/900）+ 右侧红色斜切块面（clip-path）+ 左下黑色角块 + 统计方块行；取代旧红黑斜带
6. **链接块**：Markdown 中独立成段的链接渲染为 3px 黑框 + 硬阴影的块（如互助墙入口）
7. **密度**：区块垂直 padding 收紧至 48~56px，禁止大面积留白削弱紧迫感
8. **不引入** StyleKit 的 `#8b4513` 棕色——6 色铁律不变；聊天气泡本体保持 3px 边框规格（长文可读性优先）

## 0.1 v2.1 移动端与动效补丁（2026-09-03）

1. **断点**：≥1200 桌面 / 768-1199 平板 / <768 手机；Hero 标题 `clamp()` 流式缩放
2. **手机侧栏 = 抽屉**：≤768px 时侧栏 `position: fixed` 左侧滑入（100ms linear）+ 墨黑半透明遮罩；聊天主区顶部出「会话」按钮条
3. **微动效**：新消息气泡 100ms 上移淡入；提示词 chips 交错入场（80ms，间隔 40ms）；仅挂载时触发，key 稳定不重放
4. **可访问性**：`:focus-visible` 3px 红色焦点框；`prefers-reduced-motion` 下全部动效关停
5. **滚动条**：10px 墨黑滑块 + 纸深轨道（webkit）

## 0.2 v2.2 转场与主页信息架构（2026-09-03，取代 v2.1 旧转场）

1. **转场三原则**：① 共享骨架（导航 64px）不参与转场，转场层只覆盖内容区；② 方向编码空间——深入（主页→聊天）墨块左→右扫，返回反向；③ 因果换页——墨块扫入盖旧页（旧页保持渲染），**150ms 全覆盖瞬间才交换路由**（React 侧延迟 displayed location 实现），同一块扫出揭新页
2. **单墨块 + 16px 红尾刃**：禁止多色块分离闪屏；300ms linear 一个连续动作；新页面内容 `.page-enter` 140ms 延迟落位
3. **主页首屏 = 红果万事屋简介**：它是第一个功能，简介必须在最开头——Hero 主角为「红果万事屋」（名称 + 定位句 + 白话简介 + 开始对话），WY 退居站点品牌（小标签「WY · 模块 01」+ 导航 + 页脚）；红色块面上放对话预览 mock
4. **主页结构**：Hero（简介）→ 它能做什么（三步上手 + 能力宫格）→ 未来模块 → 站点统计条 → 页脚；原模块 01 大卡片取消（信息被 Hero 吸收，避免重复）
5. **提示词 7 组**：新增「奖助竞赛」（研究生/本科奖学金、竞赛）；删除「校园卡余额」（Agent 不支持）

## 1. 设计 Token

### 1.1 颜色（全站只允许这 6 个色值）

| Token | 色值 | 用途 |
|---|---|---|
| `--paper` | `#F2E8D5` | 页面主背景（泛黄纸色） |
| `--paper-deep` | `#EAE0C9` | 侧栏、卡片内的预览区等次级背景 |
| `--paper-light` | `#F8F2E4` | 卡片、气泡、输入框等浮起面 |
| `--ink` | `#1A1A1A` | 文字、边框、黑色块、页脚 |
| `--red` | `#CC0000` | 强调：当前态、主 CTA 阴影、徽章、头像、发送键 |
| `--gold` | `#D4A843` | 极少量点缀：装饰圆点、头像、"即将上线"标识 |

**禁忌**：禁止引入任何其他颜色（包括灰色——"次要文字"用 `--ink` + `opacity: 0.45~0.6` 实现）；禁止渐变。

### 1.2 字体

```css
--font-body: "Noto Sans SC", sans-serif;   /* 中文正文 + 标题（Bold） */
--font-label: "Inter", sans-serif;         /* 英文小标签、大写宽字距 */
```

### 1.3 字阶（Type Scale）

| 层级 | 字号/行高 | 字重 | 场景 |
|---|---|---|---|
| Display | 72 / 默认 | Bold | 主页 Hero 大标题 |
| H1 | 40 / 默认 | Bold | 区块标题（"第一个功能：AI 小助手"） |
| H2 | 32 / 默认 | Bold | 卡片大标题、未来模块标题 |
| H3 | 20 / 默认 | Bold | 小卡片标题 |
| Body-L | 15 / 26 | Regular | 卡片描述 |
| Body | 14 / 23 | Regular | 聊天消息正文 |
| Body-S | 13 / 21 | Regular | 预览气泡、侧栏会话项 |
| Caption | 12 / 19 | Regular | 辅助说明 |
| Label-EN | 9~12 | Inter Bold | 英文标签，`letter-spacing: 1~4px`，全大写 |

规则：**标题只用 Bold，正文只用 Regular**，不存在中间字重；英文标签必须全大写 + 加宽字距。

### 1.4 边框（全部直角，无圆角）

| 场景 | 规格 |
|---|---|
| 细元素（导航标签、会话项、接口标签） | `border: 2px solid var(--ink)` |
| 标准（卡片、气泡、输入框、按钮、图片） | `border: 3px solid var(--ink)` |
| 强调（页面主卡片） | `border: 4px solid var(--ink)` |
| 分隔线 | 2~3px 高的 `--ink` 实色条 |

**`border-radius: 0` 全站唯一值，任何元素不得出现圆角。**

### 1.5 阴影（硬边偏移阴影，无模糊）

```css
--shadow-s: 4px 4px 0 var(--ink);   /* 小元素：按钮、输入框、小气泡 */
--shadow-m: 5px 5px 0 var(--ink);   /* 标准：气泡、预览卡、模块卡 */
--shadow-l: 8px 8px 0 var(--ink);   /* 页面主卡片 */
--shadow-red-s: 4px 4px 0 var(--red);  /* 黑底元素专用：主按钮、用户气泡、新对话按钮 */
```

规则：黑色（`--ink` 底）元素用红色阴影；其余一律黑色阴影。`blur` 永远为 0，禁止柔和阴影。

### 1.6 间距

- 页面级水平 padding：**64px**（桌面）
- 区块垂直 padding：56~72px
- 卡片 padding：主卡 48px / 小卡 24px / 气泡 14~16px
- 元素间距梯度：**8 / 12 / 16 / 24 / 32**
- 对话页主内容区水平 padding：140px（1440 宽下）

## 2. 组件规格

### 2.1 导航栏
高 64px，下接 3px 粗黑线。左侧：14px 红方块 + 站名（Bold 18）；中间链接（当前项红色 Bold，其余 `--ink`）；右侧黑框状态标签（2px 边框 + 8px 红色方块点 + Inter Bold 小字）。

### 2.2 按钮
- **主按钮**：`--ink` 底 + `--paper` 字 + `--shadow-red-s`，padding 16/30，Bold 16
- **次按钮**：透明底 + 3px 黑框 + `--ink` 字，同尺寸
- **小徽章按钮**（特性标签等）：3px 黑框 + Bold 12，padding 9/14
- Hover（建议）：阴影归零 + 元素位移（`transform: translate(4px, 4px)`），过渡 `150ms ease-out`

### 2.3 卡片
- **页面主卡片**（如"AI 助手"卡）：`--paper-light` 底 + 4px 黑框 + `--shadow-l`
- **标准卡 / 模块卡**：3px 黑框 + `--shadow-m`
- 卡内左上角可放红色 / 金色 / 黑色 12px 小方块作为分类标记

### 2.4 徽章
- 红色实心徽章（"已上线 LIVE"）：`--red` 底 + `--paper` 字 + Bold 11 + 字距 2
- 黑框文字标签（"[ UNDER CONSTRUCTION ]"）：Inter Bold 9 + 字距 2，无底色

### 2.5 聊天气泡
- **AI 气泡**：`--paper-light` 底 + 3px 黑框 + `--shadow-m`，padding 16，正文 Body
- **用户气泡**：`--ink` 底 + `--paper` 字 + `--shadow-red-s`，右对齐
- **气泡内图片**：3px 黑框，宽度撑满气泡
- **AI 头像**：32×32 `--red` 方块 + 2px 黑框 + 中间"红"字（Bold 14 `--paper`）
- **流式光标**：3×16 `--red` 竖条，跟随文字末尾闪烁
- **当前会话项（侧栏）**：`--red` 底 + 2px 黑框 + `--paper` Bold 字；其余会话项透明底 + 2px 黑框

### 2.6 输入区
顶部 2px 粗黑分隔线；输入条 `--paper-light` + 3px 黑框 + `--shadow-s`；占位文字 `--ink` 45% 透明度；发送键 44×44 `--red` 方块 + 3px 黑框 + 白色箭头图标（SVG，禁止 emoji）。

### 2.7 装饰元素
- **斜带**：绝对定位矩形色块，`transform: rotate(-8deg)`，红带（高 110）+ 黑带（高 16）成对出现，仅用于 Hero 等大型留白区，容器需 `overflow: hidden`
- **金星 / 金方块**：≤24px，每屏最多 1~2 个
- 页脚：`--ink` 实心横条 + `--paper` 字

## 3. 布局

- 设计基准宽度 **1440px**；对话页固定高 900px（侧栏 264px + 3px 粗竖线 + 主区）
- 主页为纵向滚动：导航 → Hero（高 660）→ 模块 01 区块 → 未来模块网格（3 列等宽，gap 20）→ 页脚
- 对话流宽度上限：气泡最大宽 620px

## 4. 全局禁忌（违反即走样）

1. 禁止圆角（`border-radius` 恒为 0）
2. 禁止渐变、模糊阴影、玻璃态
3. 禁止第六种颜色以外的任何颜色
4. 禁止衬线字体、斜体、轻字重
5. 禁止 emoji 当图标，一律 SVG
6. 次要文字不准用灰色，用 `--ink` + 透明度
